# Cat animation research

Checked 10 November 2026. Quality and performance are estimates, not benchmarks. The iteration 1 walk has straight-looking limbs under an oval; its end pose is the exact logo. `home/cat.js` already has four IK legs, stride-linked feet, swat and turn. Better poses, contact timing and a convincing turn matter more than another solver.

| Tool | Quality and agent/human work | What to supply; web cost and licensing |
|---|---|---|
| **Rive** | High ceiling for a responsive vector character: bones, mesh deformation, timelines and state machines. Its official [CLI writes text RML](https://rive.app/agents), builds/previews files and exchanges work with the editor. Agent authors; human critiques timing and poses. Import the SVG; draw profile limbs and transition poses. | Install CLI; provide a Rive account to publish/export and desktop editor for visual review. CLI preview is free with limits; editor has a [free tier](https://rive.app/pricing). Ship `.riv` plus [Canvas/WebGL JS and WASM runtime](https://github.com/rive-app/rive-wasm); heavier startup than SVG. Canvas Lite saves size. Verify file-URL loading. |
| **Lottie / dotLottie** | High for crafted, mostly predetermined motion; less natural for continuously targeted paw contact than a rig. [Creator MCP](https://docs.lottiefiles.com/en/developers/creator-mcp) accepts SVG, and [Creator scripts](https://docs.lottiefiles.com/en/creator-api/guides/scripting) create paths/keyframes. Agent builds; human refines. After Effects + Bodymovin is an animator alternative; test export compatibility. | Connect Creator MCP and sign in; provide SVG/pose art. Creator has free and [paid plans](https://lottiefiles.com/pricing); AE needs a subscription. JSON/dotLottie plus player: SVG player adds DOM work; dotLottie uses WASM. Cost grows with paths/keyframes. Preserve exact logo separately. |
| **GSAP + MorphSVG/MotionPath** | Medium to high with good authored poses. Agent sequences SVG and eases body/tail; morphing cannot invent anatomy or paw contact. Redraw profile/crouch/turn poses and control shape correspondence. [Plugins are now freely available](https://www.gsap.com/docs/v3/Installation/); see [MorphSVG](https://gsap.com/docs/v3/Plugins/MorphSVGPlugin/). | No account required; exact-version CDN scripts. Free under GSAP's [standard license](https://gsap.com/standard-license/), check terms for the eventual use. JS adds transfer; many path updates cost CPU. Excellent fit for the current DOM SVG and wordmark synchronization. |
| **Flubber** | Medium as a helper for a few silhouette transitions; agent can use it directly. [MIT library](https://github.com/veltman/flubber) estimates correspondence between arbitrary paths, so ears, paws and tail can melt or cross. Hand-picked in-betweens remain necessary. | No app/account; pinned JS CDN. Smaller than an engine; detailed paths increase CPU. Test the profile-to-back morph. |
| **SVG bones / IK in JS** | Medium to high if an artist supplies jointed silhouettes and keyed poses. Agent owns rigging and timing. [Kinematics](https://github.com/wylieconlon/kinematics) is an MIT JS/SVG IK example; [DragonBonesJS](https://github.com/DragonBones/DragonBonesJS) is MIT but targets engine renderers, not a drop-in SVG rig. Neither solves posing or gait design. | No license purchase needed; supply reference and layered parts. Existing analytic IK is already tiny, so a library adds bytes and complexity with little automatic quality gain. SVG nodes are cheap at this scale but per-frame path work still needs profiling. |
| **Spine** | Very high character-animation ceiling: meshes, IK and hand-tuned animation. Human animator works in the editor; agent can generate/inspect data and drive the [CLI](https://esotericsoftware.com/spine-command-line-interface), but a complete autonomous workflow is unproven here. Usually uses raster attachments. | Supply a licensed editor, layered art and optionally an animator. [Professional is needed to author IK/meshes](https://esotericsoftware.com/spine-purchase); runtime licensing is separate from MIT and integrators need a suitable license. Web player plus atlas adds payload/GPU work. Version-match editor and runtime. Likely excessive for one intro. |
| **Frame-by-frame / AI images or video** | Highest expressive ceiling with an animator's drawn extremes and in-betweens. Agent assembles sprites or traces masks with Potrace. AI concepts may drift in identity, paws and loop closure. Human must curate/correct and confirm usage rights. | Supply a coherent transparent frame set or a licensed generation service/account/API key and reference video. Sprites need no animation runtime, but atlas bytes grow with frame count/resolution and do not scale as vectors. Tracing many frames can inflate SVG and introduce flicker. AI service costs vary; retain exact logo as final SVG. |
| **Blender / Grease Pencil** | High for artist-directed 2D or a rig rendered as a black silhouette. Agent can use Python and headless rendering; human art direction still matters. [Grease Pencil can export animated SVG](https://developer.blender.org/docs/release_notes/4.5/grease_pencil/) and [render from CLI](https://docs.blender.org/manual/id/dev/advanced/command_line/render.html); verify export in target browser. | Free, open-source Blender installed locally; supply model/rig or reference. Export PNG sprites or animated SVG, so no Blender web runtime. Atlases and packed SVG frames can be large; a 3D rig needs profile styling. |
| **Cavalry / Jitter** | Good visual timeline tools; high with skilled animation, weaker direct agent control than Rive/Creator. Cavalry supports [scripting](https://docs.cavalry.scenegroup.co/scripting/) and [Lottie export](https://docs.cavalry.scenegroup.co/exporting/lottie/); Jitter exports Lottie. Human authors; supply layered art. | Install Cavalry or supply Jitter account. Check current [Cavalry pricing](https://cavalry.scenegroup.co/pricing/) and [Jitter pricing](https://jitter.video/pricing/); Jitter free exports are watermarked. Exported Lottie has player/DOM or WASM costs as above. I could not verify a supported agent API or MCP for Jitter, nor a complete headless Cavalry authoring/export workflow. |

Third-party [Blender MCP](https://github.com/ahujasid/blender-mcp), [Rive MCP](https://github.com/FUNGnix/rive-mcp) and [Spine MCP](https://github.com/zhoushengmin/spine-mcp-server) projects exist; none were installed or tested here. Rive lists state-machine serialization as future work; Spine targets 3.8.75. Treat them as experiments, not supported guarantees. Creator MCP is documented by LottieFiles; check account, import and export availability in the actual client.

## Recommendation

Use **Rive CLI + editor**, with an animator or owner review of key poses. Give the agent: (1) the existing `CAT_PATH`/logo SVG, (2) a side-view video of a real cat walking and playing, with permission to use it as reference, (3) 5–8 approved silhouette drawings or a layered SVG for profile walk, crouch, swat, sit and rear-facing logo, and (4) Rive CLI, editor and an account for export. An animator-made layered rig is the highest-value optional handoff. No API key is needed for Rive. Do a short CLI-to-`.riv`-to-browser proof first; RML coverage, export entitlement and exact CDN/file-URL support were not tested.

Build planted-foot walk poses, anticipation, paw contact, yarn recoil, recovery and a deliberate turn into the exact logo. Keep yarn and wordmark in existing SVG; signal contact and completion between JS and the Rive state machine, with a static exact-logo overlay for the final pose and reduced motion. Inspect frames at desktop/mobile size, measure actual transfer and dropped frames, and test skip/interrupt. Avoid promising pixel-perfect contact until the shared coordinate mapping is tested.

**Cheaper fallback:** keep the existing SVG IK and use free GSAP plus carefully drawn pose paths, with Flubber only where its in-betweens pass review. The owner supplies the same reference and pose drawings, no account or paid app. Use step-by-step frame captures to tune weight shifts, foot plants and tail follow-through; end on the unmodified `CAT_PATH`. An AI image/video account is optional for reference exploration, not required for production frames.
