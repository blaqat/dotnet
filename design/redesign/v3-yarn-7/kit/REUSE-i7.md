# Reuse audit · i7 (C1)

Owner: "realistically each page should be resuing the same components not introducing their own unless necessary." Every page was read for parts it made for itself where the kit already had one (chips, tags, facts, buttons, rows, cards, pills, toasts, popovers / sheets, hints, top bars, empty states, pagers, fields). Each finding below was replaced with the kit's part; where two pages had invented the same thing, one version was promoted into the kit and both now use it. The kit API is in `kit/COMPONENTS.md`; every part is live in `kit/components.html`.

## Findings

| # | Page | What it had | What it uses now |
